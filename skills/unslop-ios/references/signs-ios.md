# iOS / SwiftUI 的 slop 迹象

逐条过，命中就记一行：**位置（文件:行）→ 改法**。

## 表面与颜色

- 紫→蓝 / 粉丝带渐变的背景、卡片、按钮、选中态 → 一块中性表面，强调色只用在有含义处
- 渐变文字（标题、数字、logo） → 实心主文字色
- 彩色光晕 / `shadow(color: 高饱和)` / 给 emoji 加阴影 → 删除，深度靠表面步进与发丝线
- 内容后面有径向色斑 / 模糊光球 → 删除
- 霓虹或高对比彩色描边 → 6–10% 透明度的发丝线
- 同一色相的五个近似浅色调当文字 → 三条文字角色（主 / 次 / 三级）
- 每个元素都高亮，结果没有重点 → 一屏一两处强调
- 玻璃卡 + 白色内高光 + 彩色投影 → 普通抬起表面 + 发丝线
- **一屏叠两三层玻璃**（导航玻璃 + 卡片玻璃 + 按钮玻璃） → 只留一层

## 字号与文字排印

- 标题用 `.heavy` / `.black` 加粗堆层级 → `.semibold` 以内，用字号区分
- 全大写 + 宽字距的标签（`设置项`、`NAVIGATION`） → 正常大小写
- 一屏 5 种以上字号/字重 → `TypeScale` 里挑 2–3 个
- 数字格式混乱（`48条` / `48 条` / `48条记录`） → 统一一种
- 小字用负字距 → 零或略正
- 斜体做强调 → 换颜色或字重

## 图标

- 界面里出现 emoji（导航、按钮、状态、计数） → 换 SF Symbols 或不放
- 图标尺寸/颜色各异 → 一种尺寸、一种描边、跟随文字角色色
- 图标没落在同一列 → 每行固定图标盒宽
- ✨ 这类「AI 感」符号 → 只在真能解释功能时使用

## 间距

- 随手值（`13`、`7`、`31` 等非 4 倍数；`padding(.horizontal, 14)`） → 4pt 网格
- 同一列表行高/间距不一致 → 同高同距
- 组内间距 ≥ 组间间距（分组关系反了） → 组内小、组间大
- 兄弟卡片内边距不同 → 统一
- **同一页里卡片左缘不在一条线上**（父子容器各加一次 `hInset`） → 只由使用方加一次
- 区块上方大空白、下方拥挤 → 节奏重排

## 文案

- 问候式标题（「欢迎使用Codelumi」「你好！」） → 用页面名或时间段
- 感叹号、`！！`、`～` 堆叠 → 陈述句
- 变化量没有参照（`+8`、`少 3 个`） → `今日新增 8`、`比昨天少 3`
- 占位符啰嗦（`搜索取件码 / 快递公司 / 地址 / 驿站…`） → `搜索`
- 夸张词（赋能、无缝、超级、极致、一键解锁、重新定义、懂你） → 说它到底做什么
- 标签/按钮带句末句号 → 去掉
- 假数据（`123456`、`张三`、`XX 小区`） → 真实感的取件码与驿站名
- **同一页重复解释同一件事** → 只留一处，其余删除或降到二级页
- 引导订阅 / 销售催促 / 防盗宣示式文案 → 删除

## 组件与结构

- 每个元素都是胶囊（搜索框、按钮、卡片全胶囊） → 按尺寸给圆角，内层圆角 = 外层 − 间距
- `PRO`、`New ✨`、`Beta 🚀` 处处挂 → 只留一处克制的文字标识
- 统计卡里塞迷你柱状图/火花线 → 数字 + 标签 + 变化量就够
- 一排同款卡片，各自带同样的图表 → 一个主图 + 紧凑数字
- **同一功能两个入口**（如「快捷指令自动化」和「使用教程」） → 合并成一页
- 每行都挂一行灰色副标题 → 只留标题，内容进二级页
- 设置项顺序按实现顺序而非使用频率 → 常用在上、不常用沉底
- 空态只有「暂无数据」 → 说清为什么空、下一步做什么

## 状态与体验

- 所有按钮同权重，用户不知道点哪个 → 一主一次
- 危险操作无二次确认 / 确认要打字但数字不换 → 见 AGENTS「随机四位数字」
- 加载无反馈、失败无解释 → 原地提示 + 可重试
- 大字号下文字截断或重叠 → `FONT_STEP=6` 截图验收
- 深色模式出现白底白字 / 灰底灰字 → `APPEARANCE=dark` 截图验收
