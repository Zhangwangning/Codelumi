## 三、真机录屏脚本（标签已对 321 界面逐屏核过）

**硬要求（苹果原文）**：physical device；**开头必须是从主屏点 App 图标启动**；
付费内容路径必须出现在片子里。模拟器录屏不算。

准备：
1. 设备升到最新正式 iOS，**删掉重装** 321（TestFlight），走完首启同意 + 引导再录，
   这样录屏开头能拍出「同意条款 → 引导」两屏（苹果要看的正是这些）。
2. 先往「信息」里存 1 条样例短信，方便粘贴；或用一份备忘录存好 4 条样例。
3. 清理屏幕上的隐私：关掉通知横幅（否则会弹「张王宁」之类）、别露出 TestFlight、
   别用私人照片（相册选图请用一张干净的短信截图）。
4. 控制中心 → 屏幕录制（开麦克风可选，不需要旁白）。

按顺序（约 100 秒，全程别停）：
1. 停在**主屏幕**，手指**点 Codelumi 图标**启动。
2. 首启：条款页 → 勾选「我已阅读并同意」→「同意并继续」→ 引导三页 → 进列表。
3. 「待取」列表停 2 秒（有卡片）。
4. 右上 `+` → **「粘贴解析添加」** → 点「粘贴」→ 解析出卡片 → 「添加」。
5. 列表中点某张卡片右侧的圆圈 → 卡片移到「已取」。
6. 底部切「已取」→ 点「分组与排序」切一次（按快递公司）→「选择」勾两条 →「分享 2」→
   分享面板出现 →「完成」。
7. 底部切「统计」，停 3 秒。
8. 底部切「设置」（**顶部就是 Codelumi PRO 横幅**）→ 进「外观与个性化」→
   点「自定义 App 图标」停在图标网格 2 秒 → 返回。
9. 回设置 → 点顶部 **Codelumi PRO 横幅** → 订阅页**停 5 秒**（两档价格 + 「恢复购买」+
   页脚「隐私政策 · 使用条款」都要看清）→ **不要真的付款** → 返回。
10. 停止录屏。

交付：**YouTube「不公开」链接**（最稳，短链不占 Notes 预算）或 iCloud 共享链接。
123pan 那条别用：审核员在海外，JS 单页 + 国内主站，很可能打不开或要登录。
