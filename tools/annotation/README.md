# 人工标注 → 重训分类器

## 0. 去重

生成器会**自动去重**：去掉所有空白后完全一致的两条只保留一条
（语料里同一驿站模板反复出现，510 行去重后 332 行）。
只差数字的样本会保留 —— 那是有价值的不同样本。

## 1. 拿模板

```bash
/tmp/gen-template 短信语料库_v1.md > 标注模板.tsv
```

每行一条短信，前 9 列是**现有解析器的预填结果**，第 10 列是原文。

| 列 | 含义 |
|---|---|
| `预填` | `pickup` = 解析器认为是快递短信；`other` = 不是 |
| `取件码` / `运单号` / `尾号` / `快递公司` / `地址` / `货架` / `柜位` | 解析器抽出来的字段，空的表示没抓到 |
| `原文` | 短信全文 |
| `人工判定` | **要你填**：`pickup` 或 `other` |
| `人工取件码` / `人工地址` / `人工备注` | 可选：预填错了才填 |

## 2. 怎么标

- 只改**错的行**。预填对的留空，脚本会沿用预填值。
- 拿不准的留空即可，不会污染训练集。
- 用 Numbers / Excel 打开、改完**另存为 TSV**（制表符分隔），不要存成 xlsx。
- 自己的短信可以**追加**到文件末尾，序号接着排。

## 2.5 地址也要标（用于校正解析规则）

`标注模板_合并.xlsx` 里 **pickup 行整行淡绿**，集中核对这一批的地址：

- **M 列「人工地址」**：对的行**也请照抄一遍** Prefill 的值，错的行写正确地址；
- 只写「市/区/路/小区/门牌」这类完整地址，**不要写驿站名**（驿站名放 N 列，格式 `驿站：xxx`）。

标完跑：

```bash
python3 tools/annotation/xlsx2tsv.py 标注模板_合并.xlsx > 标注模板_合并.tsv
python3 tools/annotation/address-report.py 标注模板_合并.tsv
```

会打印**地址准确率**与差异分类（未抓到 / 截断多余 / 缺行政区 / 完全不同），
并写出 `地址差异.md`（含每条原文与两版地址），据此改地址公式。

## 2.8 并入用户从 App 导出的样本

用户在 App 里「设置 › 帮助与反馈 › 帮助改进Codelumi」添加的样本，
导出后是一份 `codelumi-training.jsonl`。直接并入标注集：

```bash
python3 tools/annotation/import-training.py codelumi-training.jsonl
```

- 默认并入 `标注模板_定稿.tsv`，已有原文按「删空白后全等」去重；
- 新增行的「预填」留空（用户标注优先），人工列填用户给的值；
- 并入后会提示条数，可直接 `retrain`。

## 3. 重训

```bash
swiftc -O -parse-as-library -o /tmp/retrain tools/annotation/retrain.swift
/tmp/retrain 标注模板.tsv
```

输出 `Codelumi/Codelumi/Resources/CodelumiPickup.mlmodel`，
然后重新构建装机即可。脚本会打印「人工改判 N 条」与测试集指标。

## 红线

- 标注文件**只在本机**，不要提交到仓库（`.gitignore` 已排除 `标注模板.tsv`）。
- 文本里有取件码与地址，属于用户数据。
