本次更新（构建 342）

这一版只做一件事：把「真正透明」的诊断做实。

上一版的诊断行只在"接口已经被调用过"时才显示，结果你截图里那行干脆没出现，
等于最有用的信息被藏掉了。现在改成：

· 接口状态细分：ok / 找不到类 / 找不到方法 / 签名不对 / 未挂上；
· 只要小组件扩展启动过、或小组件取过时间线，就会显示这行；
· 另外记下"扩展进程起来的时刻"，用来区分「挂上了但宿主没来调」和「根本没挂上」。

顺便说明为什么还没透：你截图那台机器上接口状态是空白的，
说明系统一直没重新取 descriptor（宿主有缓存），所以那条路还没被真正执行过。

1. 装 342；
2. 到桌面把旧的 Codelumi 小组件**删掉**；
3. 重新从小组件库添加一个（这一步会强制宿主重新取 descriptor）；
4. 打开「可用时使用真正透明」，看桌面壁纸透不透；
5. 进「设置 › 小组件」，把最下面那行诊断截图。
