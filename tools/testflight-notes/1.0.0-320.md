1.0.0 (320) 测试内容

新增
1. 驿站组：设置 › 驿站管理 › 「新建驿站组」，可以把同一个取件点的几家驿站（比如菜鸟驿站 + 妈妈驿站 + 丰巢）并成一个新驿站。组有自己的名称、图标和位置，待取 / 已取页只显示组，不再把成员拆成几坨。
2. 组名、图标、位置三项各自独立：都能自定义，也能「只从某一个成员继承」（继承是动态的，成员换了图标 / 位置，组立刻跟着变）。
3. 驿站管理页改成三段：驿站组 → 未归组的驿站 → 已归入驿站组（灰显，点一下回到所在组）。解散组后成员原地恢复独立显示。
4. 驿站内排序：驿站管理页顶部新增，四档 —— 收到时间新→旧 / 旧→新、取件码 0→9 A→Z / 9→0 Z→A。只在「按快递驿站」分组时生效；取件码按从左到右逐位比较，所以「8-4-1005」排在「8-4-999」前面。
5. 超时未取「重复提醒」：通知页可开，按设定间隔反复提醒，直到全部取完。
6. 到达提醒（实验室 · Codelumi Pro）：给驿站设位置，到店时若有该驿站的待取件才推通知。驿站管理里内置驿站和自定义驿站都能设位置。
7. 取件码管理：设置 › 桌面小组件 › 取件码管理。可调取件码颜色（7 档）、整码透明度、末四位是否强调、前段透明度。
8. 一张卡片多个取件码（默认关闭）：一条短信里有两个取件码时，开启后回到同一张卡；关闭则拆回一码一卡。件数统计不受影响。
9. 桌面小组件设置页改版：「显示占位符」并入「显示内容」，效果预览挪到开关下方。

修复
10. 小组件里勾选完成，桌面 / 灵动岛 / App 三端件数不再对不上。之前的回滚是：小组件只落了勾选日志、主 App 内存里还握着旧记录，任意一次写盘就会把旧状态整份写回。
11. 订阅页价格不跟随商店地区：之前只在「商品完全取不到」时才重试，一旦拿到 $0.99 就再也不刷新。现在商店地区一变就会重新取价。
12. 拍照识别首次进入会自动触发一次快门，已修好。
13. 已取页按驿站分组时，组内的顺序会被时间排序覆盖掉（选了「按取件码」也不生效），已修好。

重点验证
· 驿站管理：新建一个组，选 2–3 家驿站当成员 → 保存 → 页面上该组出现在第一段，被选走的驿站从原网格消失、出现在第三段（灰显）。
· 待取页切「按快递驿站」：同一个组只出现一个分组，组头是组名；卡片第二行应是「组名/原来的驿站名」。
· 驿站内排序切到「取件码 0→9」：同一个驿站里的取件码应按从左到右逐位递增排列。
· 解散组：成员立刻恢复成独立分组，历史记录与取件状态都不受影响。
· 到达提醒：给一个驿站设位置并启用 → 走到那个位置附近，若有该驿站待取件应收到通知（系统围栏有延迟，实测时多等一会儿；界面不划算时请反馈机型与系统版本）。
· 重复提醒：开一个 1 小时间隔，确认差不多每小时催一次，全部取完后应自动停止。
· 取件码管理：换颜色 / 降透明度后，返回待取页与桌面小组件应同步变化。
· 一张卡片多个取件码：开 / 关各看一次，开关切换应立刻对已有记录生效。

说明
· 到达提醒需要「始终允许」定位权限，只在你自己开启这个功能时才会申请；位置只存在本机，不上传。
· 桌面小组件的驿站组名与取件码样式需要真机验证（模拟器包没有 App Group，跨进程读不到）。
