1.0.0 (322) 测试内容

这一版主要改三块：驿站与驿站组、首启同意页、关于页。另外默认图标换了，设置里能换的图标仍是十七套。

新增
1. 驿站组按「一个取件地点」重做：一个驿站只属于一个组。组间排序和待取页、已取页、桌面小组件同一套（件数多的组在前，没标驿站的记录置底），不会再出现列表和小组件顺序不一样。
2. 详情页可以逐条指定驿站和驿站组：短信里只写了品牌名、分不清是哪家的时候，编辑态点「快递驿站」手动选一次就定下来；如果同一个品牌对应多个组，会提示你选一个，而不是猜。
3. 点任一驿站（含内置驿站）可以直接分组：驿站组 › 所属，选组即归组，也能当场新建一个组并把当前驿站勾进去。换组只影响之后的识别，不改历史记录的归属。
4. 关于 Codelumi 新增「开源项目」和「特别鸣谢」；「推荐给朋友」从「鼓励一下」挪到这一页。

重做
5. 首启同意页：先讲清「不联网 / 不上传 / 不用注册」，再是条款与勾选。没勾选时「同意并继续」也能点 —— 会自动勾上并弹确认框，框里点「取消」或「不同意」会退回未勾选。
6. 驿站管理页：顶部加了搜索；驿站组格子上标成员数；说明文字压成一行；点驿站能看到位置、到达提醒，以及上面的分组入口。
7. 编辑 / 新建驿站组：图标和组名合成一张卡（首字 / 相册 / 继承成员三选一），位置来源收成一行，成员列表可搜索。
8. 取件码管理页：改开关时预览立刻跟着变（之前慢一拍），预览用的是快递公司真实品牌色，说明文字大幅删减。
9. 桌面小组件设置页：「完整信息」单独一卡，其余五项一卡，说明文字全部去掉。

调整
10. 默认 App 图标换成第 7 套「黑盒立体」；十七套都能换，换过图标的用户不会被改回去。
11. 删除第三方模型通道（DeepSeek / 豆包 / 千问 / Kimi 与 API Key 全部移除）。Apple 智能只保留系统端侧能力，用来给正则解析做辅助补齐，用不了时自动退回纯正则，功能不受影响。
12. 版本历史、隐私政策、服务条款重写：不再出现收费、订阅、iPad 分栏这类表述。

重点验证
· 驿站组：建一个组放「菜鸟驿站」，确认待取页和桌面小组件里这个驿站归到组名下面，顺序两边一致。
· 换组：把「菜鸟驿站」从 A 组挪到 B 组，确认 A 组里它消失、B 组里出现；之前已归到 A 组的记录不应被改写。
· 详情页：找一条驿站没识别出来的记录 → 编辑 → 点「快递驿站」→ 选一个组 → 保存，卡片和列表应立即跟着变。
· 内置驿站分组：驿站管理 → 点「菜鸟驿站」（没有自定义过的那种）→ 底部「驿站组 › 所属」，能选组、能新建组。
· 首启同意页：新装（或删掉重装）后，不勾选直接点「同意并继续」→ 应自动勾上并弹确认；点「不同意」或框外空白，勾选要退回未勾选。
· 桌面小组件：设置 › 桌面小组件 里关掉几项，预览和小尺寸组件应立刻一致。
· 取件码管理：快速点「末四位强调」开关，预览里的前半段与末四位要即时变化。
· 设置 › Apple 智能：只应有系统端侧那一页，不应再有任何服务商列表或 API Key 输入。
