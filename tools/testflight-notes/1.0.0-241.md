测试版 1.0.0 (241)

本版新增：可选 iCloud 同步（默认关闭）
· 在「设置 › iCloud 同步」里开启后，取件记录会写进你自己的 iCloud 云盘（iCloud 云盘 › Codelumi › records.json），同一 Apple ID 的多台设备自动合并。
· 不经过开发者服务器，开发者看不到你的记录；关闭后 App 不再读写 iCloud，本机记录一条不少。
· 合并规则：同一件包裹在多台设备上都改过时保留最后改动的那份；删除的记录不会从另一台设备「复活」。页面上会显示上次同步时间，可手动「立即同步」。

本版改进：设置页重新分组（上一版 240 已含）
· 首页不再堆分组标题，功能块之间用留白分隔；「外观与个性化」「存储空间」「关于 Codelumi」收进二级页。
· 关于 Codelumi 里新增「鼓励一下」「隐私政策（简明版）」，原「声明与免责」并入服务条款。
· 新增 iCloud 同步后，隐私政策与服务条款已同步更新（App 内与网页版）。

测试重点
1. 两台设备（或 iPad + iPhone）用同一 Apple ID：A 机新增/标记已取/删除，B 机冷启动后应看到一致结果。
2. 删除的记录不要从另一台设备回来（墓碑机制）。
3. 关掉同步开关后本机记录不应减少；再打开应继续合并。
4. 未登录 iCloud 时，页面应提示「没有找到 iCloud」而不是崩溃或反复重试。
5. 设置页各二级页（外观与个性化 / 存储空间 / 关于 Codelumi / 鼓励一下 / 隐私政策简明版 / 服务条款）排版与返回。
6. TestFlight 沙盒内购不扣费；购买页价格应能正常显示。
