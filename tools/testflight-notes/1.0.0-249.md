本版（1.0.0 249）主要带来 iPad 原生支持与 iCloud 同步。

一、iPad 原生支持
· 从「iPhone 兼容窗口」改为真正的 iPad 原生运行：列表左列表右详情、设置左侧栏右侧内容；
· 标签栏改用系统原生的「可折叠侧边栏 / 顶部标签栏」（sidebarAdaptable），不再自绘；
· 补齐 iPad 尺寸的备用 App 图标（76 / 152），修复 App Store 的 ITMS-90032 / 90890 / 90892 提示；
· 实时活动、分享面板不再误用 iPhone Duo 的紧凑版式。

二、iCloud 同步（默认关闭，可选）
· 只写进你自己的 iCloud 云盘「Codelumi / records.json」，不经过开发者服务器，开发者看不到取件记录；
· 同一 Apple ID 的多台设备自动合并：同一条记录保留最后改动那份，删除的记录不会从另一台设备「复活」；
· 设置 › iCloud 同步 页有状态面板（网络 / iCloud / 同步状态 / 最近同步）与「立即同步」，同步时有转圈动画。

三、其它
· 外观与个性化新增「显示『统计』」开关：关掉后底部（iPad 顶部）只剩 待取 / 已取 / 设置；
· 锁屏实时活动的品牌图标改用静态资源渲染，修复 iPad 上图标显示成灰色方块的问题（请重点确认）；
· 修复「按需派送运单9005」这类没有取件码的申通短信：正确识别为运单尾号，并把「（兔喜快递超市）」这类括号备注从地址里去掉；
· 设置页重新分组：外观与个性化、存储空间、关于 Codelumi 收进二级页；新增隐私政策（简明版），声明与免责并入服务条款。

测试重点
1) iPad：列表/详情两栏、设置分栏、顶部标签栏、App 图标切换；2) 两台设备同一 Apple ID：A 标记已取 → B 变已取；B 删除 → A 不复活；关掉开关后本机记录不丢；3) 外观与个性化关掉「统计」后标签栏立即少一项；4) iPad 锁屏实时活动的品牌图标是否为彩色（本版重点）；5) 沙盒购买 Pro 不扣费。
