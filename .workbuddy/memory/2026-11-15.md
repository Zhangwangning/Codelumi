## 二、🔴 本机无法完整构建（环境限制，非代码问题）

`xcodebuild` 必然失败于 `CoreMLModelCompile` / `CoreMLModelCodegen`：

```
sandbox-exec: sandbox_apply: Operation not permitted
```

- 根因：Xcode 的 CoreML build rule **硬编码**用 `/usr/bin/sandbox-exec -f <profile>` 包住编译器；
  当前 agent 运行环境（seatbelt）不允许 apply 任何**非最简**策略。
- 实测边界：`sandbox-exec -p '(version 1)(allow default)'` 可以；
  加 `(import bsd.sb)`、`(disable-callouts)`、`(deny file-write* (subpath …))` 任一条即 71 失败。
- 试过且无效：`ENABLE_USER_SCRIPT_SANDBOXING=NO`、`dangerouslyDisableSandbox`。
- 手工 `coremlc generate` + `coremlc compile` 产出到 DerivedData 后重跑，仍会重建该任务 —— 绕不过。
- 结论：**构建验证必须在宿主终端（普通 shell）里跑**，或让主人跑一次；本会话内无法自证 0 warning。
  其余工程纪律（`-disable-sandbox`）不变。
